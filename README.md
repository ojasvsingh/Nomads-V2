# Nomads

A full-stack travel scrapbook app where users log memories from trips, track countries visited on an interactive world map, and get AI-generated trip plans personalized to where they've already been.

---

## Features

**Travel Map** — Click any country on an SVG world map to mark it visited, view linked memories, or jump straight to creating a new one. A live counter tracks how many of the world's 195 countries you've explored.

**Memories** — Create, edit, and delete richly detailed travel entries with a title, description, visit date, country, and uploaded photos. Memories are linked to both a user account and a specific country code so they surface correctly on the map.

**AI Trip Planner (Explore)** — Describe a dream trip in natural language and receive a personalized, markdown-formatted travel plan generated by Claude. Plans take into account where you've already been and are saved to your history so you can revisit them later.

**Dashboard** — Personal home screen showing total memories logged, countries visited, and your most recent trip, with quick-action links to every section of the app.

**Authentication** — JWT-based auth with bcrypt password hashing. Tokens are stored client-side via Zustand and sent as Bearer headers on all protected routes.

## Database Schema

Four Prisma models backed by PostgreSQL:

- **User** — account credentials, display name, bio, avatar, privacy flag
- **Memory** — travel entry with title, description, country (ISO A3 code), visit date, and photo array
- **VisitedCountry** — join table tracking which countries a user has marked visited
- **ExploreSession** — persisted AI trip-planning prompt/response pairs per user

## Getting Started

### Prerequisites

- Node.js 18+
- PostgreSQL database
- Anthropic API key

### Installation

```bash
# Install dependencies for both client and server
cd client && npm install
cd ../server && npm install
```

### Environment Variables

Create `server/.env`:

```env
DATABASE_URL=postgresql://user:password@localhost:5432/nomads
JWT_SECRET=your_jwt_secret
ANTHROPIC_API_KEY=your_anthropic_api_key
PORT=5000
```

### Database Setup

```bash
cd server
npx prisma migrate dev
```

### Running Locally

```bash
# Terminal 1 — start the API server
cd server && npm run dev

# Terminal 2 — start the frontend
cd client && npm run dev
```

The client runs at `http://localhost:5173` and the server at `http://localhost:5000`.
